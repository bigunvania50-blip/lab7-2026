# Лабораторна робота № 7. Читання та запис даних у файли

## Мета

Набути практичних навичок роботи з файлами в мові програмування Python, навчитися читати дані з файлів різних форматів, записувати дані у файли, використовуючи різні режими доступу, а також опанувати обробку помилок, пов’язаних з файловими операціями.

## Завдання для всіх варіантів

1. Створити текстовий файл, що містить деякі дані (наприклад, список імен, чисел або будь-який інший текст).
2. Написати програму на Python, яка відкриває створений файл для читання.
3. Прочитати вміст файлу та вивести його на екран.
4. Додати до програми функціонал, який дозволяє користувачеві ввести з клавіатури рядок.
5. Записати введений користувачем рядок у новий файл.
6. Додати до програми функціонал, який дозволяє користувачеві ввести ім’я файлу.
7. Прочитати вміст файлу, ім’я якого ввів користувач, та вивести його на екран.
8. Обгорнути всі операції з файлами в блоки `try-except` для обробки можливих помилок (наприклад, відсутність файлу).

## Приклад виконання завдання

### Етап 1. Створення файлу `input.txt`

Спочатку потрібно створити текстовий файл [`src/input.txt`](src/input.txt). Відкрийте будь-який текстовий редактор і введіть туди наступний текст:

```
Це перший рядок файлу.
Це другий рядок.
А це третій!
```

Збережіть файл під ім’ям `input.txt` у тій же папці, де ви будете зберігати файл з кодом програми.

### Етап 2. Відкриття та читання файлу `input.txt`

Створіть новий файл з розширенням `.py` (наприклад, [`src/lab7.py`](src/lab7.py)). У цьому файлі почнемо писати програму. Спочатку відкриємо файл `input.txt` для читання:

```python
try:
    file = open("input.txt", "r", encoding="utf-8")
except FileNotFoundError:
    print("Файл input.txt не знайдено!")
    exit()
```

Тут ми використовуємо функцію `open()`, яка приймає два аргументи: ім’я файлу та режим доступу. Режим `"r"` означає, що ми відкриваємо файл для читання. Ми обгортаємо виклик `open()` у блок `try-except`, щоб обробити помилку `FileNotFoundError`, яка може виникнути, якщо файл не знайдено.

Далі прочитаємо вміст файлу та виведемо його на екран:

```python
content = file.read()
print("Вміст файлу input.txt:")
print(content)
```

Функція `read()` зчитує весь вміст файлу як один рядок.

### Етап 3. Запит рядка від користувача

Тепер запитаємо у користувача рядок тексту:

```python
user_input = input("Введіть рядок тексту: ")
```

Функція `input()` виводить на екран передане їй повідомлення і очікує введення тексту від користувача. Введений текст зберігається у змінній `user_input`.

### Етап 4. Запис у файл `output.txt`

Відкриємо файл `output.txt` для запису:

```python
try:
    with open("output.txt", "w", encoding="utf-8") as output_file:
        output_file.write(user_input)
    print("Рядок успішно записано у файл output.txt")
except IOError:
    print("Помилка запису у файл output.txt")
```

Тут ми знову використовуємо функцію `open()`, але цього разу з режимом `"w"`, який означає запис у файл. Якщо файл `output.txt` не існує, він буде створений. Якщо файл існує, його вміст буде перезаписано. Конструкція `with open(...) as ...:` гарантує, що файл буде автоматично закритий після завершення блоку `with`, навіть якщо виникне помилка. Функція `write()` записує переданий їй рядок у файл.

### Етап 5. Запит імені файлу від користувача

Запитаємо у користувача ім’я файлу, який він хоче прочитати:

```python
filename = input("Введіть ім'я файлу для читання: ")
```

### Етап 6. Читання та виведення вмісту файлу, вказаного користувачем

Відкриємо вказаний користувачем файл для читання та виведемо його вміст:

```python
try:
    with open(filename, "r", encoding="utf-8") as user_file:
        file_content = user_file.read()
        print(f"Вміст файлу {filename}:")
        print(file_content)
except FileNotFoundError:
    print(f"Файл {filename} не знайдено!")
except IOError:
    print(f"Помилка читання файлу {filename}")
```

Тут ми знову використовуємо `open()` з режимом `"r"` та обробляємо помилки `FileNotFoundError` та `IOError`.

### Етап 7. Закриття файлу `input.txt`

Додамо закриття файлу `input.txt` після того, як ми його прочитали:

```python
file.close()
```

Закривати файли важливо для звільнення ресурсів системи та запобігання втраті даних.

### Повний код програми (`src/lab7.py`)

```python
# Відкриття та читання файлу input.txt
try:
    # Використовуємо 'with', щоб файл закрився автоматично
    with open("input.txt", "r", encoding="utf-8") as file:
        content = file.read()
        print("Вміст файлу input.txt:")
        print(content)
except FileNotFoundError:
    print("Файл input.txt не знайдено!")
    # Створюємо файл, якщо його немає, щоб програма могла продовжити роботу
    with open("input.txt", "w", encoding="utf-8") as file:
        file.write("Це перший рядок файлу.\nЦе другий рядок.\nА це третій!")
    print("Створено демонстраційний файл input.txt. Будь ласка, запустіть програму знову.")
    exit()
except IOError as e:
    print(f"Помилка читання файлу input.txt: {e}")
    exit()

# Запит рядка від користувача
user_input = input("Введіть рядок тексту для запису в новий файл: ")

# Запис у файл output.txt
try:
    with open("output.txt", "w", encoding="utf-8") as output_file:
        output_file.write(user_input)
    print("Рядок успішно записано у файл output.txt")
except IOError as e:
    print(f"Помилка запису у файл output.txt: {e}")

# Запит імені файлу для читання
filename = input("Введіть ім'я файлу для читання (наприклад, input.txt або output.txt): ")

# Читання та виведення вмісту файлу, вказаного користувачем
try:
    with open(filename, "r", encoding="utf-8") as user_file:
        file_content = user_file.read()
        print(f"Вміст файлу '{filename}':")
        print(file_content)
except FileNotFoundError:
    print(f"Помилка: Файл '{filename}' не знайдено!")
except IOError as e:
    print(f"Помилка читання файлу '{filename}': {e}")

```

### Пояснення до коду

1.  **`open()`**: Функція для відкриття файлів. Приймає ім'я файлу та режим (`"r"` - читання, `"w"` - запис/перезапис, `"a"` - дозапис).
2.  **Методи читання**:
    *   `read()`: Читає весь файл як один рядок.
    *   `readline()`: Читає один рядок.
    *   `readlines()`: Читає всі рядки і повертає їх як список.
3.  **`write()`**: Записує рядок у файл.
4.  **`close()`**: Закриває файл. Важливо для звільнення ресурсів.
5.  **`with open(...) as ...:`**: Конструкція, яка автоматично закриває файл після завершення блоку, навіть при помилках. **Це рекомендований спосіб роботи з файлами.**
6.  **`try-except`**: Блоки для обробки помилок, таких як `FileNotFoundError` (файл не знайдено) та `IOError` (помилка введення-виведення).
7.  **`input()`**: Отримує дані від користувача.
8.  **`print()`**: Виводить дані на екран.
